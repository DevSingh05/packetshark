# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work and
not the person, and no harassment of any kind. This applies to issues, pull
requests, discussions and anywhere else the project is represented.

## Reporting

If someone's behaviour here is a problem, report the content with GitHub's
"Report content" option, found in the menu on any comment, issue or pull
request, which reaches the maintainer and GitHub. The maintainer will look
into every report, keep the reporter's identity private, and may edit or
remove content, or block a participant, in line with the Covenant's
enforcement guidelines.
